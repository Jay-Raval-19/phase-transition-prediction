# Phase Transition Prediction

Machine-learning experiments for predicting phase transitions in stochastic systems using tabular simulation features.

---

## Repository Contents

| File | Description |
|---|---|
| `AlphaLife-ML.ipynb` | Training and evaluation pipeline for the alpha-life stochastic dataset |
| `TemporalStoc-ML.ipynb` | Training and evaluation pipeline for temporal stochastic data |
| `SpatialStoc-ML.ipynb` | Training and evaluation pipeline for spatial stochastic data |
| `datasets/alpha_life_dataset.csv` | Alpha-life dataset |
| `datasets/temporal_stochastic_dataset.csv` | Temporal stochastic dataset |
| `datasets/spatial_stochastic_dataset.csv` | Spatial stochastic dataset |
