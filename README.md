+# Phase Transition Prediction
+
+Machine-learning experiments for predicting phase transitions in stochastic systems using tabular simulation features.
+
+## Repository Contents
+
+- `AlphaLife-ML.py` — training and evaluation pipeline for the alpha-life stochastic dataset.
+- `TemporalStoc-ML.py` — training and evaluation pipeline for temporal stochastic data.
+- `SpatialStoc-ML.py` — training and evaluation pipeline for spatial stochastic data.
+- `datasets/` — CSV files included in this repository.
+- `datasets/alpha_life_dataset.csv`
+- `datasets/temporal_stochastic_dataset.csv`
+- `datasets/spatial_stochastic_dataset.csv`
